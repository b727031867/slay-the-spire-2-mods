[h1]旅行者·元素连携 / Traveler Elements[/h1]
[b]0.3.19 · 支持单人和联机 · 简体中文/英文[/b]
可选角色「旅行者」拥有38张专属奖励牌（13攻击/18技能/7能力）、10张起始牌，以及专属遗物、四个主题事件和旅行者契约。通过风、岩、雷的出牌顺序组合防御、过牌和追击。

[h2]0.3.19：性能与稳定性修复[/h2]
[list]
[*]角色动画改为复用顶点与骨骼缓冲，逐帧不再重复分配，多人同屏时开销更低。
[*]战斗结束时释放出牌去重记录，长战斗不再持续累积引用；同回合内的重复结算保护不变。
[*]事件选项字号适配按整页合并为每帧一次，内容与窗口尺寸未变时跳过重排，避免反复触发布局。
[*]自动测试改为增量读取日志，严格检查器与失败判定不变；这只影响开发工具，不改变游戏内容。
[/list]
玩法、数值、卡牌、遗物与事件效果均未改动。此前0.3.18的十张罕见牌与全部调整照常生效；完整升级与规则见玩家指南。

[h2]0.3.18：十张罕见牌[/h2]
[list]
[*]循风寻径：从抽牌堆选择岩或雷元素牌入手；升级后不消耗。
[*]借风藏势：抽2（3）张牌，再选择1张手牌本回合保留。
[*]岩脊反击：7（10）伤害；已有格挡时再施加2虚弱。
[*]层岩回响：每回合首次实际风岩奖励后，获得1（2）本回合敏捷。
[*]踏石蓄势：8（11）格挡、7（10）原生活力。
[*]余雷引航：7（9）格挡，下回合额外抽2；升级后不消耗。
[*]蚀雷针：5（8）伤害、3（4）原生中毒。
[*]携毒之风：全体3（4）原生中毒、抽1。
[*]毒雾行囊：每回合首次实际雷风奖励后，全体2（3）原生中毒。
[*]沉毒岩障：7（10）格挡；有存活中毒敌人时再获得3基础格挡。
[/list]
全部1费罕见牌，起始卡组不变。0.3.18 的规则与升级说明保持不变，详见玩家指南。

[h2]连携规则[/h2]
[list]
[*]风↔岩：4格挡；岩↔雷：4基础追加攻击；雷↔风：抽1张。双向可触发。
[*]默认每人每回合合计3次，有任一罗盘时4次。连携后保留最新元素，跨回合保留，战斗结束清空；普通无元素牌不打断。
[*]单体攻击追击原存活目标，死亡不转火；无敌方目标的技能随机追击；无目标群攻不自动选目标。
[*]普通自动出牌和重复结算不推进；元素调律选中牌与三相灌注效果为明确例外。抽0、零伤害或无有效目标不计实际奖励。
[*]元素之心在雷霆余响加成后翻倍基础连携奖励，不翻倍能力或罗盘额外收益。
[/list]

[h2]保留此前平衡及修复[/h2]
雷蚀回响固定增加每种已有可叠层负面3（6）层或回合；负力量、负敏捷再降低相同点数，不翻倍。远征战鼓每回合第2次实际奖励后蓄势，下一张主动单体攻击首段基础伤害翻倍。雷霆余响1（0）费，攻击/格挡加2（4）、抽牌加1，不可叠加；棱晶只为每回合首张无元素牌随机赋予元素。塔外来信恢复5生命，开战失去2生命。
保留Boss能力牌追加奖励、药水的未来事件、密封牌组候选和建筑师通关结算修复，以及旅行者能量球、计数器和元素音效。

[h2]四个主题事件[/h2]
地图之外的岔路、失准的测绘台、寄自塔外的信、最后一位引路人。队伍至少一名旅行者即可遇到；各自选择并领取角色适用的奖励。包含永久元素改造、契约、同伴分支及归途诅咒。

[h2]安装与验证[/h2]
Windows x64，游戏v0.107.1/build23811903，BaseLib3.4.7。工坊依赖不能锁版本，本Mod拒绝其他BaseLib版本。每个Mod只保留一份生效副本；联机各方须使用相同游戏、Mod及BaseLib版本。
本次改动仅涉及动画缓冲、连携状态清理、事件字号刷新与测试工具日志读取，玩法逻辑未变。按用户要求验证受影响的无GUI专项后发布，未运行Full。图形观感、自然整局平衡、旧档及真实联机尚未验收；此前版本双人联机反馈不代替本版本验证。卡图含生成式素材，工坊封面和规则图为说明素材，不是游戏截图。

[h2]English[/h2]
Traveler Elements 0.3.19 is a performance and stability update with no gameplay changes. The Traveler rig now reuses its vertex and bone buffers instead of allocating every frame, combat-end releases the card dedupe set, and event option font fitting is coalesced to one pass per page and skipped when layout is unchanged. The reward pool stays at 38 cards: 13 Attacks, 18 Skills and 7 Powers, including the ten 0.3.18 Uncommon cards. Four themed events support parties with at least one Traveler. Development log polling is incremental; the strict validators are unchanged.
Requires Windows x64, game v0.107.1/build23811903 and BaseLib 3.4.7. All multiplayer clients need matching versions. Affected headless suites passed; Full, graphical playtesting and real multiplayer were not run for this release. User playtesting follows publication. This item and future updates remain public. Unofficial fan mod, not affiliated with Mega Crit.
