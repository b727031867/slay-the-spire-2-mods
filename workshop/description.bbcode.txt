[h1]旅行者·元素连携 / Traveler Elements[/h1]
[b]0.3.9 · 单人技术测试版[/b]
可选角色「旅行者」拥有18张专属奖励牌（7攻击/7技能/4能力）、10张起始牌、旅途罗盘和专属遗物「派蒙的应援」。支持简体中文/英文，通过风、岩、雷出牌顺序组合防御、过牌和追击。

[h2]本次更新[/h2]
[list]
[*]战斗角色统一使用原始母稿的七层网格与18关节，保持脸型、服装与比例一致；剑与持剑手保持刚性，双脚维持支撑。
[*]普通攻击改为侧身前突刺，防御改为双手握柄举剑挡在身前，受击改为轻微侧身后仰，各动作结束回归原始姿态。
[*]连续出牌在突刺和防御之间直接衔接当前姿势；修正命中时钟瞬跳、剑刃拉伸与抬剑时副手翻转。
[*]沿用既有卡牌与连携规则、商店旅行者、篝火坐姿、三元素攻防特效和融合反馈。
[/list]

[h2]连携规则[/h2]
[list]
[*]风↔岩：额外4格挡；岩↔雷：额外4基础攻击；雷↔风：额外抽1。
[*]两种出牌方向均可，三类每人每回合合计最多3次。连携后保留刚打出的元素，可连续衔接；元素跨回合保留，战斗结束清空。
[*]单体攻击追击同一存活敌人，原目标死亡不转火；无敌方目标的防御技能随机追击。无目标群攻不自动选择单体追击目标。
[*]派蒙只翻倍基础连携，不翻倍罗盘/能力；能力牌不带元素，不推进序列。
[*]自动打出与额外重复结算不推进序列；战斗结束跳过奖励，零伤害/抽0等未发放奖励不计入能力的实际连携次数。
[*]元素共鸣在每回合第2次实际连携奖励时回能；旅途罗盘触发后隔一次自己的回合恢复。
[/list]

固定 Windows x64、游戏v0.107.1/build23811903与BaseLib3.4.7；本Mod会拒绝其他BaseLib版本。工坊依赖无法锁定版本，更新后请核对。每个Mod只保留一份生效副本。
构建、完整回归及实际下载检查记录在发布报告。用户已完成动作草图及本地回放评审；AI游戏测试全程无GUI，离线回放来自实际节点网格帧，不能替代实机光照与特效下的画面验收。多人、自然完整流程/Boss平衡和旧档迁移未作系统验收。条目沿用既有好友可见设置，需有访问权限。
角色、卡牌与篝火插图使用生成式素材。封面与规则图为原创说明设计，不是游戏截图。NPC商人及部分通用演出仍复用原生资源。

[h2]English[/h2]
Version 0.3.8 removes long combo overlays from card selection and keeps one short preview for playable hand cards. The Traveler's head/body ratio, waist, coat, legs and elbow connections are recalibrated while combat animations are preserved. Shops now display the Traveler with a dedicated scene and a compatibility guard for native Spine animation calls. Rest-site art and elemental effects remain available.
18 exclusive reward cards including 4 Powers, a ten-card starting deck, Journey Compass and Paimon's Cheer. Gameplay values, combo limits and save IDs are unchanged. Each element pair works in either order and all pairs share a three-use cap per player per turn; elements persist across turns. Paimon doubles only base combo rewards. Targeted follow-ups never replace a dead target; defensive skills choose a random living enemy using native RNG.
Pinned baseline: Windows x64, v0.107.1/build23811903, BaseLib3.4.7. Full regression and download verification are recorded in the release report. Headless checks and offline pose reconstructions do not establish in-game rendered appearance. Multiplayer, natural full-run/Boss balance and old-save migration are not systematically validated. AI-generated illustrations are used; previews are explanatory graphics. Private visibility is preserved.
