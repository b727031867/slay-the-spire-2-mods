[h1]旅行者·元素连携 / Traveler Elements[/h1]
[b]0.3.7 · 单人技术测试版[/b]
可选角色「旅行者」拥有18张专属奖励牌（7攻击/7技能/4能力）、10张起始牌、旅途罗盘和专属遗物「派蒙的应援」。支持简体中文/英文，通过风、岩、雷出牌顺序组合防御、过牌和追击。

[h2]本次更新[/h2]
[list]
[*]新增11部件分层2D战斗动作：普通挥剑、防御、全挡、部分格挡受伤、直接受伤、倒地与复活。
[*]风、岩、雷分别提供攻击和防御特效；连携按实际奖励显示融合反馈，派蒙强化突出表现，不增加虚假打击次数。
[*]篝火使用旅行者专属坐姿休息图，保留原生各幕环境、休息/锻造按钮和选项气泡。
[*]卡池、伤害、格挡、抽牌、连携额度和存档ID保持。角色状态图标与只读卡牌悬停预览保留。
[/list]

[h2]连携规则[/h2]
[list]
[*]风↔岩：额外4格挡；岩↔雷：额外4基础攻击；雷↔风：额外抽1。
[*]两种出牌方向均可，三类每人每回合合计最多3次。连携后保留刚打出的元素，可连续衔接；元素跨回合保留，战斗结束清空。
[*]单体攻击追击同一存活敌人，原目标死亡不转火；无敌方目标的防御技能随机追击。无目标群攻不自动选择单体追击目标。
[*]派蒙只翻倍基础连携，不翻倍罗盘/能力；能力牌不带元素，不推进序列。
[*]自动打出与额外重复结算不推进序列；战斗结束跳过奖励，零伤害/抽0等未发放奖励不计入能力的实际连携次数。
[*]元素共鸣在每回合第2次实际连携奖励时回能；旅途罗盘触发后隔一次自己的回合恢复。
[/list]

[h2]English[/h2]
Version 0.3.7 adds layered 2D combat animation for the Traveler: sword attacks, defense, fully and partially blocked hits, hurt, death and revival. Wind, Rock and Lightning each have attack and defense effects, with fused feedback for actual combo rewards. A custom seated Traveler illustration now appears at rest sites while native rest/smith options remain.
18 exclusive reward cards including 4 Powers, a ten-card starting deck, Journey Compass and Paimon's Cheer. Gameplay values, combo limits and save IDs are unchanged. Each element pair works in either order and all pairs share a three-use cap per player per turn; elements persist across turns. Paimon doubles only base combo rewards. Targeted follow-ups never replace a dead target; defensive skills choose a random living enemy using native RNG.
Pinned baseline: Windows x64, v0.107.1/build23811903, BaseLib3.4.7. The user approved the development build after playtesting; clean release checks are recorded separately. Headless tests do not establish rendered appearance. Multiplayer, natural full-run/Boss balance and old-save migration are not systematically validated. AI-generated illustrations are used; previews are explanatory graphics. Private visibility is preserved.
