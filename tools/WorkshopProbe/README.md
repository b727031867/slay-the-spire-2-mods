# Headless Steam Workshop probe

Uses the Steam client and Steamworks.NET package shipped in Mega Crit's official uploader source (v0.2.0). It inspects item state and preview URLs, explicitly subscribes and asks Steam to download the item, explicitly unsubscribes, or explicitly replaces one gallery image. Use unsubscribe only for test-owned subscriptions whose prior state was recorded, or on the user's instruction. It never copies files into the Steam cache, uploads mod binaries, accepts agreements, or changes visibility implicitly. The explicit public and friends-only commands change only visibility after checking game identity and current-account ownership. Requires Steam running and signed in.

Download the official `steam/Steamworks.NET.15.0.1.nupkg` into an ignored local NuGet feed, restore with `dotnet restore --source <feed>`, and build normally. Copy `steam_api64.dll` from the official Windows uploader alongside the executable. Set `SteamAppId` and `SteamGameId` to `2868840` for this process only. Run `WorkshopProbe.exe inspect <id>` or `subscribe <id>` hidden. A successful download does not prove game loading or dependency compatibility.

Source: https://github.com/megacrit/sts2-mod-uploader/tree/v0.2.0/steam . Record the package hash and uploader version in each acceptance report. Do not publish raw Steam logs or account details.

For an authorized broken gallery-image repair, first run `inspect <id>` and fetch each returned image URL. Use `replace-preview <id> <index> <image-path>` only after identifying the broken image index. This submits a preview-only Steam update, requires an existing Slay the Spire 2 image slot and a PNG/JPEG below 1 MB, and preserves the cover, mod files and visibility. After success, run `inspect` again, download the new URL and compare its SHA-256 with the source image. An upload callback alone does not prove the CDN file is readable. If submission times out, inspect remote state before retrying.

For the user-authorized public policy dated 2026-10-25, run `WorkshopProbe.exe public 3823282901` hidden with the configured .NET environment and process-local Steam app IDs described above. This submits only a visibility change; it leaves mod content, title, description, previews and dependencies untouched. An already Public item is a no-op. Run `inspect` afterward and require `k_ERemoteStoragePublishedFileVisibilityPublic`. On timeout inspect before retrying; never treat a submit callback as remote verification. The older friends-only command remains available for an explicit future user request, but is not the current policy and must not be used just for friend playtests.
