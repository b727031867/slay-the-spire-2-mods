## 交互

- 状态栏按无/风/岩/雷使用四种有独立轮廓和颜色的矢量UI图标，图标随实际出牌状态刷新；不再只靠悬停说明。
- 战斗左上常驻元素面板，图标+元素名、剩余次数与三枚指示点、格挡/基础追击/至多抽牌三种奖励图标；不拦截鼠标、不获取焦点。
- 原生手牌悬停、选中/拖拽（含原生控制器/快捷键选择）读取同一原生HoveredModelTracker；选中优先。有效连携高亮对应奖励区域，显示下一张牌的元素图标；当前元素仍保留，直到实际打出才更新。
- 同元素/首次记录不高亮；费用不足或不能出牌不承诺奖励；次数0时奖励区变暗。派蒙同步4/8、1/2。随机追击只显示随机模式，不提前取随机数。攻击明确基础伤害及原目标存活条件，抽牌是上限，不承诺绕过禁抽或满手。
- 非手牌、非元素牌、卡牌选择流程不做连携高亮。战斗结束、死亡、离开战斗界面隐藏，节点随原生战斗UI释放，无常驻静态卡牌/玩家引用。
