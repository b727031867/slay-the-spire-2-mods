## 规则

- 无旅行者不出现；有一名或多名旅行者均可，幕范围不变，不按旅行者人数增加权重。
- 岔路：其他角色的三选一来自本角色已解锁奖励池，第三层稀有牌；生命、金币、诅咒规则相同。
- 测绘台：旅行者规则不变；其他角色第一张升级免费，第二张60金币，仅可升级牌，无候选可离开，取消不收费。
- 信件：旅行者三契约不变；其他角色塔外来信开战失去2生命、自己第三回合结束恢复3生命且每战一次；地址更正首回合少抽1，生成本角色非稀有未升级奖励牌，本回合免费且虚无；无人认领沿用普通奖励规则。
- 引路人：旅行者三遗物不变；其他角色从适用、已解锁、未拥有的原生普通遗物随机抽取最多三件，免费选一；候选不足按实际数量，无候选可离开。
- 其他角色的生成牌排除X费与不可打出牌，避免“本回合免费”的错误承诺。所有效果以Owner为准。
