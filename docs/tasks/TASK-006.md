# TASK-006：连续元素连携

用户要求：不同元素配对后保留刚打出的元素，下一张元素牌可以继续触发相邻组合。

规则：风→岩→风触发两次风岩；风→岩→雷触发风岩与岩雷。每人每回合共享 3 次上限、奖励值及派蒙翻倍保持原样。同元素只更新记录；普通牌不打断；自动出牌和额外重复结算不推进。无目标岩雷仍占次数并记录最新元素；达到上限后继续记录，但不发放奖励。回合结束、死亡和战斗结束仍清空记录。

版本 0.1.4，沿用 `codex/TASK-005-experience` 分支。验证进行中：纯规则包括 729 种六张元素牌序列与独立相邻配对预期比较；游戏验收覆盖有/无派蒙的三费连续连携、连续抽牌、共享上限、无目标跳过后的衔接及预览。单人无 GUI，图形观感、自然整局平衡和联机需另测。
