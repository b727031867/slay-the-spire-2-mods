# 0.3.18 十张罕见牌扩展

2026-10-30用户确认：实现最初六张候选（含踏石蓄势、余雷引航的修订）及四张原生中毒牌；缺失美术按现有风格生成。只运行这十张牌的定向用例，通过后直接发布原创意工坊，由用户发布后试玩。此特定授权不记作人工验收通过，不更改后续发布的一般规则。

## 影响评估

- 基线：origin/main e8fec1a；游戏v0.107.1/build23811903、BaseLib3.4.7。
- 改动：TC_C29–TC_C38卡牌、两种能力Power、RewardCardTypes注册、中英文描述、PNG及AtlasTexture；奖励池增至38张（13攻击/18技能/7能力，10普通/23罕见/5稀有）。起始组不变。
- 直接调用：现有ComboResolver通过TravelerAbilityPower.OnComboReward派发新能力；不修改共享连携结算。检索使用当前实例元素（含测绘/棱晶改造），保留使用原生GiveSingleTurnRetain；中毒、活力和次回合抽牌均使用原生Power。
- 风险：新卡改变卡池和元素调律候选分布；活力可被岩雷追击消耗，作用于多段攻击每段；中毒可被雷蚀回响固定加3（6）层，不恢复旧翻倍规则。
- 必跑：构建、加载身份/资源/未知错误检查、NewCards十牌专项（基础/升级、选择边界、回合时效、活力多段/追击、中毒/人工制品/击杀、能力叠加及重置）；中英文键与脚本语法检查。
- 不跑：旧Cards、Character、Events、Full、磁盘恢复、图形和联机。用户明确限制本次只测新增牌；现有套件内受卡池数量影响的预期同步更新但不执行。
- 扩大条件：发现本次卡牌无法隔离的共享机制缺陷时先修最小根因，仍不擅自运行Full。
