## 原因与行为

原生TouchOfOrobas.GetUpgradedStarterRelic只为原版初始遗物提供映射，其他遗物回退为Circlet。固定BaseLib3.4.7已提供CustomRelicModel.GetUpgradeReplacement扩展接口，旅途罗盘此前未实现。

- JourneyCompass覆盖GetUpgradeReplacement，返回TC_R03 / UnboundJourneyCompass / 无界罗盘；复用原生事件预览、获得、移除旧遗物和替换流程，没有新增事件Harmony补丁。
- 升级版沿用罗盘图标，使用独立模型ID及中英文说明，每次实际发放连携奖励后额外抽1。没有回合次数预算或冷却，也不显示容易误解的0次计数。
- 通过IComboRewardRelic接入原有实际奖励回调，原版罗盘状态机不变。自动出牌、重复结算、战斗结束、无实际奖励及连携次数耗尽沿用既有限制；派蒙不翻倍罗盘抽牌。连携自身每回合共享3次上限未移除。
- 原生奖励成功替换原始罗盘，新模型及已配置事件奖励的原生序列化往返均通过。没有自动把存量头环改成罗盘，也没有将用户旧档迁移计为通过。
