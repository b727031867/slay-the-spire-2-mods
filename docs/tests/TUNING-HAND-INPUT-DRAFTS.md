## 输入修复

元素调律在三选一候选及敌方目标选择期间，只阻止持有者本机手牌的鼠标/手柄确认入口和手牌快捷键。先取消已有拖牌；用finally恢复原锁状态，保证正常结束、异常和取消均能解除。选中牌自动结算前解除锁，保留风息涤尘等牌本身的手牌选择能力；不修改全局行动状态或队友输入。

本机原生 NPlayerHand 的手牌快捷键会在检查能否出牌前取消目标选择，因此同时拦截 OnHolderPressed 与 _UnhandledInput。三选一和目标选择仍沿用原生命令与同步机制。

新增六个基础/升级×三元素用例，在候选选择中调用真实手牌确认入口及合成快捷键事件，确认不会进入拖牌/排队状态，并在结算后解除锁；另有一个异常中断解锁用例。均在headless进程内执行，不向用户桌面发送输入。
