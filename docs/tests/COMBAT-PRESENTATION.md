## 人工验收与交付界限

所有无GUI结果只证明所列逻辑、资源、事件和清理，AI图形测试与多人为NOT_RUN。用户已进行试玩评审，但未提供贴图接缝、关节遮挡、实际武器方向、命中观感、快速模式可读性及自然完整流程的逐项验收结论。当前素材为以原立绘重新生成的分层版本，不能用原立绘静态预览代替拼接后的画面验收。
