## 实现

- 新卡复用原生伤害、格挡、减益、消耗、X 费和选牌命令。乘隙雷击的层数计算使用原生动态伤害预览；天地交征始终为技能，先锁定角色元素和原生 X 快照，再执行分支。
- 调律按默认元素从奖励池等概率生成三张新实例，使用原生三选一及同步的目标选择。未选实例直接移除，选中牌使用原生单次消耗标记并免费结算。连携资格仅授予该选中实例，额外重复结算不重复推进。
- 棱晶在首张牌主要效果之前赋予元素，原生元素被覆盖；用 BaseLib SavedSpireField 保存战斗实例标记。未写入永久牌库，复制实例不继承。已赋元素在战斗牌说明中显示。
- 灌注份数统一存于能力 Amount，每个正常触发点只随机一次。回合开始在所有 early 重置之后处理。临时敏捷记录实际增量，回合结束只扣回本效果增量。效果连携共享额度、实际奖励计数及旧能力/遗物联动。
- 神像在占用连携额度时触发，使用本机原生 PlatingPower。已从本机原生资源包核对中文标题为“覆甲”，中文说明与源码均为回合末给格挡、回合开始减少 1 层；沿用该行为，不自行实现“受击减层”。只读资源核对日志为 `.local/expansion/native-plating.log`。
- 药匣监听原生实际消耗事件；战鼓在第 3 次实际奖励后就绪，仅下一张主动单体攻击的首段增伤。战鼓就绪在卡牌说明中单列，避免把首段奖励显示成每段加伤。
- 中英文说明与池注册同步更新。新卡和新遗物复用现有插画/图标；没有新增专属美术。

## 原生 X 费边界

天地交征使用 ResolveEnergyXValue，接受 Chemical X 等原生 X 值修正。免费自动结算沿用 CardCmd.AutoPlay：捕获当时能量而不扣除能量，不把这张牌改成永久 0 费。普通费用归零（SetToFreeThisTurn）不会改写原生 X 费支付规则，本实现不另行覆盖它。风分支回能在该快照确定后执行。X=0 不发起零段伤害或负数抽牌/回能。

说明中的岩/雷系数为基础值，先乘 X，再各应用一次原生格挡/伤害修正；不会先给每份系数加敏捷/力量再乘 X。

## 当前交付口径与未单独确认语义

以下两项已在开发中提问，用户尚未逐项答复，随后要求停止恢复测试并直接提交代码。当前按下列口径交付，不把未确认边界视为额外验收承诺：

1. 恢复沿用原生战斗入口磁盘回滚，以及同步动作/回放机制；没有新增跨进程精确恢复到选牌/选目标界面的存档系统。原生普通 run 存档本身没有任意中途卡牌结算快照，网络重连/回放交互未作本轮实测。
2. 灌注被自动打出或额外重复结算时是否执行即时灌注。当前实现是每次能力效果结算均执行其即时效果，普通自动出牌的牌面连携仍被拒绝。
