## 新增/更新的关键用例

- 新版初始罗盘：没有抽牌；第3次实际奖励加1力量，第4次不重复，第5次连携被阻止；跨回合累加、新战斗清除；跳过奖励不计力量进度。
- 顺风整备基础/升级均抽1；基础消耗、升级进入弃牌而非消耗。
- 风之庇护基础5格挡/单体1虚弱，升级7格挡/全体1虚弱。
- 蓄雷升级6格挡且不消耗，原生下回合能量只结算一次。
- 雷霆连锁3/4次原生随机目标命中，总伤害9/12，整张牌仅记录一次雷元素。
- 雷霆余响：一份风岩6格挡、岩雷6基础攻击、雷风抽2；与派蒙同持分别为8、8、2，不能相加。多份余响相加后仍与派蒙取较高值。
- 风的指引覆盖风雷和风岩，两类共享每回合一次；可以和派蒙的基础连携奖励同时发生。
- 基础共鸣第2次实际奖励回能，升级共鸣第1次回能；混合持有分别计数，第三次不重复。
- 三相终击升级为1费、12基础伤害，连携伤害加成最多+12，原生力量/虚弱/易伤下预览与实际结果一致。
