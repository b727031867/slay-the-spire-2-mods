## 方法

先运行不依赖游戏的连招规则断言，再从干净S构建、部署到真实游戏，以 `-TravelerTest` 创建 `ShouldSave=false`、seed=TC001A的独立铁甲局。使用原生PlayCardAction队列和原生结束回合动作；测试夹具补能量、移除战斗手牌、治疗玩家、提高靶子生命，不把这些当成正常数值或自然通关验证。

`-TravelerRewards`使用独立测试局，以原生Kill快速结束战斗，保留原生奖励的随机三选一，观察者只读且返回未修改。手动点击选择主题牌，检查原生永久牌组变化；不是直接向永久牌组生成卡牌。

界面由Computer Use在真实游戏窗口中检查并点击操作。原始日志留在忽略的`.local/logs/`，只提交本项目输出及一条奖励获取结果，不上传环境、账号ID或存档。
