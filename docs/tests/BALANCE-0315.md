## 实现与边界

- ComboState在共享Reserve入口累计CombosThisCombat。自动出牌/重复结算、同元素或额度用尽的转换不增加；正常选择调律牌和灌注的有效效果连携沿用该入口。BeginTurn只重置回合计数，ClearCombat清除战斗累计。
- 三相终击使用原生CalculatedDamageVar读取战斗累计，不改写永久牌库。牌在本场战斗中生成或抽到时读取当前累计；升级仍同时增加2基础伤害、降低1费用。
- 雷霆连锁使用原生全体目标与多段攻击命令，移除原随机追击特例；岩雷组合按无目标群攻规则处理。
- 碎岩重击通过卡牌原生伤害加值钩子额外加入两份力量，与原生一份力量合计三倍。牌面DamageVar预览与实际主攻击走同一钩子；连携奖励结算用finally限定普通力量修正。
- 磐岩之心删除旧格挡保留逻辑，以本人回合开始的原生固定格挡命令实现；壁垒或模糊保留的格挡可叠加本次新格挡。
- 共鸣的新卡均应用同一个ElementResonancePower，并按打出顺序记录每份回能值。回合使用既有实际奖励序号，不因跳过奖励推进；回合重置后从第1个位置重新触发。若该回合某位置已过去，之后才打出的对应份数不追发奖励。连携本身3/4次上限不变。
- 保留旧TC_FIRST_ELEMENT_RESONANCE模型ID及其表现检查，防止直接删除既有模型标识；新卡不再生成此旧能力。未承诺旧版任意战斗中途能力快照迁移。
