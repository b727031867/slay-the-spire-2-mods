# 当前项目约定

本页仅列仍适用的约定，版本与决策演进统一见[更新日志](player/CHANGELOG.md)。

- PC-A和PC-B均可开发、构建与测试，通过同一GitHub仓库接续，各设备独立配置和验证。
- 共享接续分支为main，新任务使用codex/前缀分支；保留本地改动，仅在可快进时同步，不强推或硬重置。
- 基线为游戏v0.107.1/build23811903、精确BaseLib3.4.7、Godot.NET4.5.1和net9.0；详见[技术基线](TECH_BASELINE.md)。
- 独立旅行者拥有18张奖励牌（4能力）与10张起始牌，完整规则以[玩家指南](player/README.zh-CN.md)为准。
- 元素跨回合保留、战斗结束清空，每人每回合共享3次连携；派蒙只翻倍基础奖励，共鸣第2次实际连携回能、每份每回合一次。方案B未实现。
- 罗盘每战首次可用，触发后的下一次自己回合冷却、再下一次恢复，未触发保留，额外回合计入。
- 界面为原生状态栏四种元素图标、卡牌悬停预览和原生能量图标，没有左上常驻面板。
- 单人先行，多人、旧档迁移及自然Boss系统性平衡独立验收，未执行不记通过。
- AI游戏测试遵守根目录AGENTS.md：无GUI、唯一隔离原生存档、无Steam云，不复制用户档案，只清理本轮测试进程。
- 包必须记录源码S、SHA256、设备及验证范围，文档提交不能替代包来源，重新构建不能沿用已试玩包身份。
- 工坊使用私有条目3823282901及依赖3737335127，避免重复加载；公开发布由用户决定。
- 源码和文本经Git同步，安装包通过可访问Release附件或正常Steam下载交接；个人配置、游戏文件、原始日志、凭据与用户数据不入库。
