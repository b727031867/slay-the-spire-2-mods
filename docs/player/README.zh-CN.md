# 旅行者·元素连携 / Traveler Elements

《杀戮尖塔 2》单人技术测试版，Mod 版本 0.3.1。可选角色「旅行者」拥有18张专属奖励牌（含4张能力）、起始遗物「旅途罗盘」与专属罕见遗物「派蒙的应援」。支持简体中文和英文文本。0.3.1使无敌方目标的防御技能也可触发岩雷随机追击，并替换19项正式图片；卡牌数值保持0.3.0。

0.1.4将连携改为相邻元素连续触发；0.1.3新增卡牌悬停规则、手牌出牌前连携提示、动态派蒙奖励提示、六张生成式卡图和透明遗物图标，以及短暂连携特效。预览只显示当前规则下的可能奖励，不消耗次数；原目标需在基础效果后仍存活，且战斗仍在进行。岩雷显示的是基础攻击值，不等同于实际扣血。抽牌不足时，触发提示显示实际张数。

## 兼容范围与安装

当前仅验证 Windows x64、游戏 v0.107.1（Steam build 23811903）及 **BaseLib 3.4.7**。其他游戏或依赖版本尚未验证；本 Mod 会拒绝加载不同版本的 BaseLib。工坊 BaseLib 会随作者更新，订阅依赖不等于锁定 3.4.7。

目前处于发布候选验收阶段，尚未提供通过完整订阅安装验收的公开工坊版本。工坊条目可用后，需要订阅本 Mod 和前置 BaseLib，并在游戏模组管理中启用。不要同时保留本地版与工坊版，否则可能重复加载。

手动安装候选包：

1. 退出游戏，下载候选 ZIP，并对照同名 `.sha256` 核对 SHA256。
2. 从 BaseLib 作者发行页下载 **v3.4.7**：https://github.com/Alchyr/BaseLib-StS2/releases/tag/v3.4.7 。将其中 BaseLib 的 DLL、JSON、PCK 放入游戏目录的 `mods/BaseLib/`。
3. 将候选包中的整个 `Sts2Mod` 文件夹放入游戏目录的 `mods/`，形成 `mods/Sts2Mod/Sts2Mod.json` 等文件。候选包不包含 BaseLib 或游戏程序集。
4. 通过 Steam 启动游戏，在模组管理中确认 BaseLib 和 Traveler Elements 已启用，按游戏提示重启。选择「旅行者」开始新的单人游戏。

玩家无需安装开发用 .NET SDK、Godot 编辑器或 PowerShell 脚本。发行包附带的 `build-info.txt` 用于识别来源。

## 旅行者开局

- 初始生命 75、能量 3、金币 99；启用模组后可在原生选人界面选择旅行者。
- 起始卡组 10 张：打击×3、防御×3、风起之刃×1、岩之守护×1、雷光突刺×1、顺风整备×1。
- 打击和防御为旅行者自己的基础牌，1费造成6（9）伤害 / 获得5（8）格挡，不附带元素、不打断连携，也不出现在普通卡牌奖励中。
- 起始遗物旅途罗盘：每回合第一次实际获得连携奖励时额外抽1张。无目标跳过或连携抽牌实际0张不消耗罗盘；罗盘自身的抽牌受原生限制，尝试后即消耗本回合次数。自己的下回合（含额外回合）恢复一次机会，派蒙不翻倍罗盘抽牌。
- 派蒙不在开局赠送，仍需从旅行者专属遗物来源获得。铁甲战士和其他角色的正常卡池不再加入这些元素牌或遗物。
- 当前奖励池为7攻击/7技能/4能力，稀有度8普通/7罕见/3稀有。商店可正常提供能力牌，Boss可提供本角色稀有牌。
- 战斗角色、选人头像及背景现使用统一正式生成式插图，战斗沿用2D属性动画；营地、商人、能量及部分通用演出仍复用原生素材，不是全新骨骼动画。

磐岩之心不生成新格挡：本回合结束最多保护4（6），敌方回合已打掉的格挡不会返还；多份上限相加，原生壁垒/模糊保护较多时不削减其保护。新卡、能力、起始打击/防御、罗盘及角色资源已使用正式生成式插图，见[本轮美术预览与来源](../art/TASK-009-prompts.md)。

## 元素连携

主动打出主题牌会记录元素。不同元素组成下列组合时，先结算卡牌基础效果，再尝试发放连携奖励；两个方向均可触发。

| 组合 | 额外奖励 | 持有派蒙时 |
| --- | --- | --- |
| 风 ↔ 岩 | 4 点格挡 | 8 点格挡 |
| 岩 ↔ 雷 | 4 点基础攻击；防御技能随机攻击一名存活敌人，单体攻击追击原目标 | 8 点基础攻击 |
| 雷 ↔ 风 | 抽 1 张牌 | 抽 2 张牌 |

每人每回合三种连携合计最多 3 次。触发后保留刚打出的元素，供下一张元素牌继续衔接：风→岩→风触发两次风岩，共额外获得 8 点格挡（持有派蒙时 16 点）；风→岩→雷先触发风岩，再触发岩雷。到达上限后仍记录最新元素，但不再发放连携奖励。普通牌不打断记录，同元素更新记录；自动出牌和额外重复结算不推进序列。元素跨回合保留，新回合仅恢复3次连携额度；整个战斗结束才清空元素记录。

岩雷奖励由无敌方目标的技能触发时，从场上存活敌人中按原生战斗随机数选一名攻击；仅有一个Boss时必定攻击该Boss。单体攻击触发则继续追击原目标，原目标死亡或移除不改选；无目标群攻也不会自动挑一个追击目标。该次组合仍占一次额度，战斗已结束则跳过奖励。随机追击与定向追击同样受力量、虚弱、易伤、格挡等原生攻击规则影响；有效追击可触发余响、共鸣和罗盘，零伤害不算能力所需实际奖励。

「派蒙的应援」进入旅行者专属罕见遗物池，可在原生遗物来源出现；不会固定赠送。它使每次成功连携的奖励翻倍，不额外提供固定格挡，重复持有不叠加。

## 存档、更新和卸载

建议使用新的模组单人档体验，并在更新、停用或切换版本前自行备份存档。自动化验证使用独立测试档，未覆盖你的正常档案；已验证原生战斗入口保存恢复，不承诺任意动作中途接续。

更新前退出游戏，手动安装时替换整个本 Mod 文件夹，避免混合旧文件；工坊版本由 Steam 下载更新。原有含本 Mod 卡牌或遗物的局可能依赖本 Mod，先结束该局再卸载。手动版删除 `mods/Sts2Mod`；工坊版取消订阅并确认下载处理完成。BaseLib 被其他 Mod 使用时应保留。卸载不会自动清理存档，也不保证含自定义内容的旧档可在停用后继续。
