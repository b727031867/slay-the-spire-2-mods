# 旅行者·元素连携 / Traveler Elements

《杀戮尖塔2》角色Mod，支持单人和联机。此前版本已完成用户双人联机实测。本指南描述0.3.13：包含19张卡池的平衡调整、无界罗盘、联机选人修复，以及遗物、连携和元素共鸣的轻量触发反馈。版本实际交付与验收状态见[项目状态](../STATUS.md)。当前旅行者拥有19张专属奖励牌（4能力）、10张起始牌及3种专属遗物（含初始遗物升级），支持中英文，版本变化见[更新日志](CHANGELOG.md)。

角色状态栏中，风为青绿气流、岩为金色晶石、雷为紫色闪电，无元素为灰色空环；图标随实际出牌改变。战斗手牌旁的「本次主动出牌预览」提示将触发的格挡、追击或抽牌以及相关限制；同元素/首次记录、不能出牌和次数耗尽时显示对应文字。选牌、奖励和牌库不再附加连携预览或整段规则，避免遮挡相邻卡牌。预览不改变当前元素或消耗次数，也不会提前取随机追击目标。左上不再显示额外面板或三个大型奖励图标。

预览只显示当前规则下的可能奖励，不消耗次数；原目标需在基础效果后仍存活，且战斗仍在进行。岩雷显示的是基础攻击值，不等同于实际扣血。实际收益通过原生伤害、格挡和抽牌反馈显示，不再另弹一层文字气泡。

## 兼容范围与安装

当前仅验证 Windows x64、游戏 v0.107.1（Steam build 23811903）及 **BaseLib 3.4.7**。其他游戏或依赖版本尚未验证；本 Mod 会拒绝加载不同版本的 BaseLib。工坊 BaseLib 会随作者更新，订阅依赖不等于锁定 3.4.7。

[工坊条目3823282901](https://steamcommunity.com/sharedfiles/filedetails/?id=3823282901)沿用既有的好友可见设置，需有访问权限。各版本实际Steam下载与工坊加载的验证范围见发布报告。安装时启用本Mod和精确版本BaseLib，核对实际文件。不要同时保留本地版与工坊版，否则可能重复加载。

手动安装已校验发布包：

1. 退出游戏，下载发布 ZIP，并对照同名 `.sha256` 核对 SHA256。
2. 从 BaseLib 作者发行页下载 **v3.4.7**：https://github.com/Alchyr/BaseLib-StS2/releases/tag/v3.4.7 。将其中 BaseLib 的 DLL、JSON、PCK 放入游戏目录的 `mods/BaseLib/`。
3. 将发布包中的整个 `Sts2Mod` 文件夹放入游戏目录的 `mods/`，形成 `mods/Sts2Mod/Sts2Mod.json` 等文件。发布包不包含 BaseLib 或游戏程序集。
4. 通过 Steam 启动游戏，在模组管理中确认 BaseLib 和 Traveler Elements 已启用，按游戏提示重启。选择「旅行者」开始单人游戏；联机各方须使用相同版本及同一份Mod包。

玩家无需安装开发用 .NET SDK、Godot 编辑器或 PowerShell 脚本。发行包附带的 `build-info.txt` 用于识别来源。

## 旅行者开局

- 初始生命 75、能量 3、金币 99；启用模组后可在原生选人界面选择旅行者。
- 起始卡组 10 张：打击×3、防御×3、风起之刃×1、岩之守护×1、雷光突刺×1、顺风整备×1。
- 打击和防御为旅行者自己的基础牌，1费造成6（9）伤害 / 获得5（8）格挡，不附带元素、不打断连携，也不出现在普通卡牌奖励中。
- 起始遗物旅途罗盘：每回合连携上限4次。每回合第3次实际获得连携奖励后，获得1点本场战斗力量；每回合至多一次，无额外抽牌。
- 派蒙不在开局赠送，仍需从旅行者专属遗物来源获得。铁甲战士和其他角色的正常卡池不再加入这些元素牌或遗物。
- 当前奖励池为8攻击/7技能/4能力，稀有度8普通/8罕见/3稀有。商店可正常提供能力牌，Boss可提供本角色稀有牌。
- 左上角头像为同角色面部特写；战斗使用同母稿七层网格与18关节动画，包含普通攻防、格挡/受伤分支、倒地与复活，风/岩/雷各有攻防特效。连携与遗物使用下文的轻量反馈。篝火使用旅行者专属坐姿休息图，商店左侧使用旅行者立绘；休息/锻造、商品与商人交互沿用原生流程。能量及部分通用演出仍复用原生素材。素材来源见[说明](../ASSETS.md)。

## 元素连携

主动打出主题牌会记录元素。不同元素组成下列组合时，先结算卡牌基础效果，再尝试发放连携奖励；两个方向均可触发。

| 组合 | 基础奖励 | 一份雷霆余响 | 派蒙（或派蒙＋一份余响） |
| --- | --- | --- | --- |
| 风 ↔ 岩 | 4点格挡 | 6点格挡 | 8点格挡 |
| 岩 ↔ 雷 | 4点基础攻击 | 6点基础攻击 | 8点基础攻击 |
| 雷 ↔ 风 | 抽1张 | 抽2张 | 抽2张 |

岩雷由防御技能触发时随机攻击一名存活敌人，单体攻击则追击原目标。每份雷霆余响增加2点基础攻击、2点格挡和1张抽牌；与派蒙不相乘、不相加，逐项取较高值。风的指引额外抽牌与罗盘收益另行结算，可与派蒙同时生效；风雷和风岩共享指引的每回合首次机会。基础/升级元素共鸣分别在每回合第2/第1次实际奖励后回能，混用时各按自己的触发点结算。

每人每回合三种连携默认合计最多3次；持有旅途罗盘或无界罗盘时最多4次。触发后保留刚打出的元素，供下一张元素牌继续衔接：风→岩→风触发两次风岩，共额外获得 8 点格挡（持有派蒙时 16 点）；风→岩→雷先触发风岩，再触发岩雷。到达上限后仍记录最新元素，但不再发放连携奖励。普通牌不打断记录，同元素更新记录；自动出牌和额外重复结算不推进序列。元素跨回合保留，新回合恢复当前上限的连携额度；整个战斗结束才清空元素记录。

岩雷奖励由无敌方目标的技能触发时，从场上存活敌人中按原生战斗随机数选一名攻击；仅有一个Boss时必定攻击该Boss。单体攻击触发则继续追击原目标，原目标死亡或移除不改选；无目标群攻也不会自动挑一个追击目标。该次组合仍占一次额度，战斗已结束则跳过奖励。随机追击与定向追击同样受力量、虚弱、易伤、格挡等原生攻击规则影响；雷霆连锁触发岩雷时也随机追击一名存活敌人。有效追击可触发共鸣和罗盘，零伤害不算能力所需实际奖励。

「派蒙的应援」进入旅行者专属罕见遗物池，可在原生遗物来源出现；不会固定赠送。它使每次成功连携的奖励翻倍，不额外提供固定格挡，重复持有不叠加。

## 触发反馈：轻量方案

| 场景 | 显示方式 |
| --- | --- |
| 罗盘、无界罗盘、派蒙触发 | 顶部遗物图标内短闪约0.24秒；不在人物头顶放大遗物图片 |
| 元素共鸣（含升级）触发 | 角色状态栏原能力图标内短闪约0.24秒；取消放大图片和图片粒子，保留原生回能反馈 |
| 风岩连携 | 生效位置绘制小型金色护盾轮廓 |
| 岩雷连携 | 命中位置绘制小型紫色折线 |
| 雷风连携 | 角色附近绘制两笔青绿色气流 |

连携线条约0.22秒、半径不超过28像素，不放大、不使用图片或粒子；同一位置的连续触发合并为一个短效节点。移除额外文字气泡和派蒙大金环；原生数值、抽牌动画、遗物计数与手牌预览保留。不修改其他角色遗物、普通元素攻防动作、奖励结算或随机数。设计范围见[轻量特效说明](../design/COMPACT-TRIGGERS-2026-10-22.md)；实际屏幕观感仍需游戏内人工确认。

## 存档、更新和卸载

支持新的模组单人局或联机局。联机时所有玩家应使用相同游戏版本、同一份Mod测试包和相同BaseLib版本，在大厅选择角色并准备后开始。更新、停用或切换版本前自行备份存档。自动化验证使用独立测试档，未覆盖你的正常档案；已验证原生战斗入口保存恢复，不承诺任意动作中途接续。

更新前退出游戏，手动安装时替换整个本 Mod 文件夹，避免混合旧文件；工坊版本由 Steam 下载更新。原有含本 Mod 卡牌或遗物的局可能依赖本 Mod，先结束该局再卸载。手动版删除 `mods/Sts2Mod`；工坊版取消订阅并确认下载处理完成。BaseLib 被其他 Mod 使用时应保留。卸载不会自动清理存档，也不保证含自定义内容的旧档可在停用后继续。
