# 旅行者专属卡池扩充提案

2026-10-20。状态：用户已完成评审，明确授权实现全部12张新牌；执行任务为TASK-008、目标版本0.3.0。现有六张奖励牌和两张基础牌保留。下方保留评审时的设计与分批建议，实际按本次授权一次完成全部12张。

## 本轮已授权的规则前提

元素在回合结束、敌方回合和自己的回合开始均保留，仅在整个战斗结束时清空。每回合仍恢复3次连携次数；达到上限后继续记录最后主动打出的元素，下回合可以接续。原生额外回合也恢复次数。

旅途罗盘改为每回合第一次实际获得连携奖励后额外抽1。目标不存在或连携抽牌被阻止时不消耗罗盘；自身尝试抽牌后即消耗本回合次数。派蒙只翻倍三种基础连携奖励，不翻倍罗盘或下列能力牌收益。

## 建议规模及构筑方向

先从6张奖励牌扩充为18张：新增4张攻击、4张技能、4张能力。最终7攻击/7技能/4能力，稀有度8普通/7罕见/3稀有。不改起始牌组。18张仍是小卡池试验阶段；这一步解决持续收益、群攻、高费终结和元素接续选择，后续依据试玩再扩为完整角色规模。

1. 风雷循环：抽牌、低费用和保留，稳定接续元素；输出仍需要攻击牌，避免纯过牌自动造成伤害。
2. 风岩守势：稳定格挡、有限跨回合保留和反击，支持慢速战斗；不提供无上限护甲或无限成长。
3. 岩雷追击：较高伤害、群攻和易伤，用三次连携额度安排爆发。
4. 三元素混合：一回合三次连携提供奖励，作为通用成型方向；不把“三种元素”误等同于“三种连携都必须触发”。

能力牌不带元素、不推进序列；所有触发按实际发放的连携奖励判断，无目标跳过和抽0均不触发。基础攻击击杀结束战斗时也不再发放战斗内触发收益。

## 建议实施与评审点

建议先确认4张能力的方向和“派蒙仅翻倍基础连携奖励”边界，再确认配套8张及数值。通过后先实现4能力与C11/C12共6张（卡池达到12张），完成专项及全量验收；第二批再补剩余6张，达到18张。期间Boss原生稀有度回退及商店补位继续保留，直到完整稀有度与类型均可靠覆盖。

测试重点：能力多份叠加、每回合次数归属、原生额外回合、回合跨越接续、禁抽/满手/死亡目标、能力触发不递归、派蒙/罗盘边界，以及新卡模型存档/奖励/商店/升级。能力不能把一次逻辑连携变成多次次数推进。

目前不建议加入：无限提升连携上限、免费无限切换元素、永久无限成长、以全部抽牌次数驱动伤害。先观察新罗盘每回合抽牌和跨回合元素保留的实际强度，再追加这些高风险机制。
