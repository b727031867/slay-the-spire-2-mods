# 旅行者四个专属事件：需求确认

确认日期：2026-10-22。状态：需求已确认；本文不代表已实现、已测试或已发布。数值为首版设计值，后续调整需另行记录。

2026-10-23实施与验证进展见[0.3.16事件验证记录](../tests/TRAVELER-EVENTS-0316.md)，当前玩家规则见[玩家指南](../player/README.zh-CN.md)。本文保留原始确认与当时未定事项。

## 共同定位

- 为同一个旅行者角色设计四个专属事件，分别承担冒险、构筑、剧情、遗物体验。四个事件只对旅行者开放。
- 故事属于高塔世界的原创冒险，主题为“追寻不存在的出口”。氛围诡异、真假难辨，同时保留一点希望。
- 四个事件独立遇到，顺序不限，通过线索相互呼应，不依赖遇齐四个事件才能成立。
- 玩家可以看清选项的实际收益和代价；真假难辨体现于剧情，不以隐藏惩罚代替选择。
- 冒险、构筑事件在第一、二幕出现；剧情、遗物事件在第二、三幕出现。
- 共同叙事方向：罗盘指向不可能的道路，高塔似乎了解旅行者寻找出口的愿望。人物关于“上一次到访”等说法不直接坐实失忆或循环。

## 一、冒险事件：地图之外的岔路

最多三层，逐步深入。每层可以收手离开，已获得的收获保留；进一步深入承担新的代价。

| 阶段 | 代价 | 收获 |
| --- | --- | --- |
| 第一层 | 失去5点生命 | 获得35金币 |
| 第二层 | 再失去7点生命 | 增加一次旅行者卡牌三选一奖励，可跳过选牌 |
| 第三层 | 获得诅咒“归途” | 二选一：获得60金币并恢复12点生命；或旅行者稀有牌三选一 |

- 各层奖励累积；第三层奖励是此前收获之外的额外奖励。
- “归途”加入永久牌组，无法打出，没有额外负面效果，仅通过占用抽牌和手牌位置形成负担。
- “归途”可正常移除；可在战斗中被风息涤尘消耗并与旅人药匣联动，战斗中消耗不等于从永久牌组删除。
- 剧情方向：墙后出现旅行者自己的路标、仍有余温的无人营地、传来风声的门；走到尽头后可能回到入口，但收获真实存在。具体正文待编写。

## 二、构筑事件：失准的测绘台

- 从永久牌组中选择最多两张无元素牌进行改造。
- 可选类型为攻击、技能、能力，排除状态牌和诅咒；不改造已有元素的牌。
- 每张分别自行指定风、岩或雷元素，两张可以选择相同元素。
- 元素改造持续本局游戏，费用、原有效果和升级状态保持原样。
- 第一张免费；完成后可直接离开。第二张支付60金币。
- 不足两张符合条件的牌时，按实际数量处理。
- 剧情方向：测绘台声称旅行者的一种元素“不属于你”，测量结果是否可信保持悬念。

## 三、剧情事件：寄自塔外的信

与一位礼貌、耐心、严格遵守投递手续，却令人不安的陌生邮差交涉。信件记录刚刚发生的经历，寄件人与投递时间的解释彼此矛盾。

通过签收、核验记录、购买退件等交涉路线，选择一份持续本局的投递契约。每份契约均有持续收益和持续代价，签约前展示完整规则；允许拒绝签约并离开。

### 塔外来信

- 每场战斗开始时失去2点生命。
- 每场战斗首次实际获得风岩、岩雷、雷风三种不同连携奖励后，恢复3点生命。
- 顺序不限，不要求同一回合完成；每场战斗只恢复一次。

### 地址更正

- 每场战斗开始时，从旅行者奖励池中随机生成一张自带风、岩或雷元素的未升级牌，加入当前手牌。
- 只存在于本场战斗，不加入永久牌组。
- 为该牌附加虚无，本回合可免费打出。
- 持续代价：每场战斗首回合少抽1张牌。
- 虚无按原生规则处理：留在手中时于回合结束消耗；打出后遵循该牌原有去向。若原牌不消耗，正常进入弃牌堆，后续抽到恢复正常费用，仍保留虚无。

### 无人认领

- 此后普通战斗卡牌奖励增加1个候选。
- 每领取一张普通战斗奖励牌，支付15金币；金币不足时不能领取。
- 跳过该次卡牌奖励时获得10金币。
- 上述规则仅作用于普通战斗卡牌奖励。

## 四、遗物事件：最后一位引路人

老测绘师认得旅行者的罗盘，声称替他保管着工具。玩家免费从三件全新的事件专属遗物中选择一件，没有隐藏扣费或额外惩罚。

| 遗物 | 首版效果 |
| --- | --- |
| 穿墙之钉 | 每回合首次岩雷连携追击实际命中后，对该次追击的目标施加1层易伤 |
| 回声线轴 | 每回合首次风岩连携实际获得奖励后，随机对一名存活敌人施加1层虚弱 |
| 逆行怀表 | 本局游戏持有期间，每回合连携上限增加1 |

- 逆行怀表将默认上限由3提高至4，持有旅途罗盘或无界罗盘时由4提高至5。
- 每回合正常重置额度，不逐回合累加，不重置其他触发计数。
- 怀表不提高卡牌自身的收益上限，例如雷霆迸发仍最多追加4段。
- 剧情方向：工具分别象征打开道路、留住来路、重走一步；老人声称旅行者“出发前已经付过钱”。
