# 战斗演出讨论稿

状态：讨论，尚未授权实现。用户选择分层2D动画及适中强度，原有角色身份和美术风格保持。

## 目标

让身体、持剑手、武器和衣摆各自运动，动作与实际命中对齐。先做好普通攻击、元素技能、防御/受击、能力施放和倒地，再评估稀有牌专属演出。保持快速出牌节奏，不用长动画阻塞结算或改变随机数、额度与伤害。

## 建议第一阶段

- 普通攻击：短蓄力、重心前移、挥剑弧线、命中、回收；剑尖拖尾与敌人命中位置对齐。
- 风：轻快前送或横斩，青绿短弧；岩：有重量的抬手/落点，金色碎屑或盾面；雷：快速出手、紫色短电光，避免持续闪白。
- 防御与受击：护盾出现和短暂后仰区分，格挡不套用完整受伤动作；避免频繁大幅震屏。
- 连携：在本次动作上叠加一次明显但短促的元素反馈，派蒙做轻量强化；罗盘抽牌/能力触发用较小反馈，避免抢主动作。
- 分层素材建议：前后衣摆/披风、躯干、头部、前后上臂/前臂/手、武器、前后腿脚。需要补齐被遮挡的关节和背景，不能仅将原图切成硬片旋转。
- 初始时间建议：普通出手约0.3–0.45秒，技能约0.4–0.6秒；快速模式缩短，连携叠加而非串长队列。实际以游戏钩子与试玩节奏评审为准。

## 技术确认项

当前只有单张body.png，Attack仅20px整体位移，Cast仅4%缩放。先核对游戏/基础库的动画触发钩子是否接入自定义AnimationPlayer；命中与实际伤害事件对齐，动画中断、敌人死亡、额外结算和快速连续出牌不能残留节点或扭曲姿态。不按卡名猜命中次数，不提前读取随机目标。

无GUI检查覆盖资源、节点、钩子、释放及逻辑只读性；动作观感、遮挡、缩放和节奏需另行人工试玩。下一步建议先评审一个普通挥剑动作样例，再扩为风/岩/雷和防御动作。
