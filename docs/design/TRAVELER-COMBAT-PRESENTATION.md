# 战斗演出方案

状态：用户已确认本轮战斗演出及篝火休息图试玩通过，授权提交、合并main并更新工坊；0.3.7发布验证见[报告](../tests/RELEASE-037.md)。采用分层2D动画及适中强度，沿用原有角色身份、服装和配色；分层素材基于原生成立绘重新生成。用户试玩反馈与无GUI检查分别记录，不代表多人或自然完整流程已系统验收。

## 目标

让身体、持剑手、武器和衣摆各自运动，动作与实际命中对齐。先做好普通攻击、元素技能、防御/受击、能力施放和倒地，再评估稀有牌专属演出。保持快速出牌节奏，不用长动画阻塞结算或改变随机数、额度与伤害。

## 建议第一阶段

- 普通攻击：短蓄力、重心前移、挥剑弧线、命中、回收；剑尖拖尾与敌人命中位置对齐。
- 风：轻快前送或横斩，青绿短弧；岩：有重量的抬手/落点，金色碎屑或盾面；雷：快速出手、紫色短电光，避免持续闪白。
- 防御与受击：护盾出现和短暂后仰区分，格挡不套用完整受伤动作；避免频繁大幅震屏。
- 连携：在本次动作上叠加一次明显但短促的元素反馈，派蒙做轻量强化；罗盘抽牌/能力触发用较小反馈，避免抢主动作。
- 分层素材建议：前后衣摆/披风、躯干、头部、前后上臂/前臂/手、武器、前后腿脚。需要补齐被遮挡的关节和背景，不能仅将原图切成硬片旋转。
- 初始时间建议：普通出手约0.3–0.45秒，技能约0.4–0.6秒；快速模式缩短，连携叠加而非串长队列。实际以游戏钩子与试玩节奏评审为准。

## 普通攻击、防御与受击动作

普通动作作为分层2D动画的基础，元素动作沿用相同的重心、关节和恢复规则，再调整出手姿势并附加元素特效。人物的肩、肘、手腕、躯干和衣摆应有先后运动，不能只移动整张立绘。

| 情形 | 人物动作 | 配套反馈与建议时长 |
| --- | --- | --- |
| 普通攻击 | 重心稍后移、肩臂带剑蓄力，随后躯干转向目标、前臂挥剑，衣摆稍后跟随，最后收剑回到待机。首版做一个清楚的斜斩。 | 一道淡白剑弧，实际命中点出现短促接触火花；约0.3–0.45秒。人物保留在己方站位，小幅前倾即可，不必跑到敌人身前。 |
| 普通防御：获得格挡 | 双膝微屈、身体压低，持剑前臂抬到身前形成防守姿态，空手辅助平衡，随后放松回到待机。 | 获得格挡的瞬间出现中性浅色盾弧；约0.3–0.4秒。使用虚拟盾面，不额外给人物添加实体盾牌。 |
| 被攻击：全部格挡 | 命中时肩臂短促收紧、身体轻微后压，剑与前臂维持防守位置，迅速恢复。 | 身前盾弧出现接触闪光或小涟漪；约0.15–0.25秒。不播放完整受伤后仰。 |
| 被攻击：部分格挡且损失生命 | 身前先出现一次格挡接触，躯干随后短促后仰、持剑手略微散开，再重新稳住姿态。 | 一次连续反应中结合盾面接触和局部受伤光，不串联两套完整动作；约0.2–0.35秒。 |
| 被攻击：直接损失生命 | 肩膀带动躯干后仰、头部稍后跟随，手臂与衣摆惯性摆动，脚下站位保持稳定，然后回正。 | 受击位置短暂低强度暖色闪光；约0.2–0.35秒，不整个人持续闪白或大幅弹飞。 |

### 触发、中断与恢复

- 普通防御出牌时的“获得格挡动作”和敌人命中时的“挡住攻击动作”是两个独立时刻；获得格挡不意味着立刻被攻击，也不强制整回合保持举剑姿势。
- 受击反应根据实际结算的格挡吸收量与生命损失选择，不能只检查角色原先是否有格挡。零伤害、免疫或其他抵消没有损失生命时，不播放受伤反馈；持续扣血等非攻击伤害使用轻量生命受损反馈，不虚构武器接触或格挡动作。
- 多段攻击的接触点按实际命中显示；连续受击时从当前姿态平滑转入短促反应，限制后仰幅度，不让恢复动画排成长队或让角色越震越远。
- 受击可以打断出手的回收段，致死后的倒地具有最高优先级；被打断的旧动作不能在结束回调中把角色拉回待机。动作被中断不取消或重复卡牌与伤害结算。
- 待机保留轻微呼吸与衣摆摆动，作为动作之间的自然衔接；不额外添加持续发光。快速模式缩短起手与恢复，接触瞬间仍需清楚可见。

首轮样例应同时包含“普通斜斩、普通防御、全挡反应、部分格挡受伤、直接受伤”，确认人物确实在挥剑、防守和承受冲击后，再扩展六套元素特效。

## 元素攻击与防御：六套基础特效

每种元素各有一套攻击、一套获得格挡的特效。除了配色，还通过轮廓、运动方向和人物姿态区分：攻击从人物向目标释放，防御围绕人物向内收拢。以下名称仅作为制作代号，不增加技能或规则。

| 元素 | 攻击特效 | 防御特效（获得格挡） |
| --- | --- | --- |
| 风 | **风刃掠斩**：身体前倾、持剑手快速横挥，青绿细长弧线沿剑尖前送；目标处出现一次短促切风，尾部散成细流。整体轻快、锐利。 | **回风护幕**：身体微沉、空手向内引风，两道青绿风带从身体两侧卷向身前，形成开放式弧面，随后散去。轮廓柔软、流动，不做持续龙卷。 |
| 岩 | **岩锋重击**：肩臂先蓄力，再做短促下劈；剑路附着金色棱角岩锋，目标处迸出少量石屑与短暂裂纹光纹。通过动作停顿和碎屑表现重量。 | **岩片结盾**：重心下压、前臂抬起，三至五片琥珀色多边形岩片从身侧升起，在身前合拢成盾面，边缘亮一下后消散。轮廓厚实、稳定。 |
| 雷 | **闪雷突刺**：身体小幅前探、持剑手迅速刺出，紫色窄电线贴合剑路，命中点短暂分叉后立即收束。突出速度，避免全屏闪白。 | **雷纹护阵**：持剑手收至身前、空手展开，紫色细电弧连接数个节点，组成紧贴身前的弧形网面；通电一瞬后渐隐。电弧不延伸至敌人，避免暗示反伤或额外攻击。 |

### 动作与反馈时序

- 攻击沿“准备 → 出手 → 实际命中 → 回收”组织；剑光跟随武器，目标特效只在对应攻击实际执行时出现。伤害被格挡时使用格挡接触反馈，不用夸张的受伤爆裂。
- 防御沿“收势 → 实际获得格挡 → 盾面成形 → 渐隐”组织，建议约0.3–0.45秒。首版采用短暂的获得格挡反馈，不常驻护盾模型，避免暗示额外持续状态。
- 敌人攻击被格挡时，接触反馈与获得格挡的演出分开；只有能够可靠确认防御元素来源时才复用对应元素纹样，否则沿用通用格挡反馈。
- 同一张牌既攻击又获得格挡时，使用一次人物动作，按真实结算顺序分别播放命中特效和护盾特效，允许尾迹自然重叠，不重复完整起手。岩系攻防混合牌可用“下劈后收剑护身”的连续动作。
- 抽牌、获得能量或单纯切换元素只使用小型施法光纹，不凭元素标签播放攻击或护盾。未实际产生的效果不播放成功反馈。

## 连携特效与基础特效的配合

连携只强化实际奖励对应的反馈，不把两个元素的完整动画依次重放。奖励结算时加一段短促的融合特效，保持基础动作清晰。

| 连携组合 | 实际奖励的演出设计 |
| --- | --- |
| 风 ↔ 岩 | 获得额外格挡时，风带推动棱角岩片在身前合拢，形成“回风岩盾”；只在人物附近出现。 |
| 岩 ↔ 雷 | 额外攻击实际命中时，目标接触点出现带紫色电纹的金色岩锋与少量碎屑，形成“雷贯岩锋”；目标以实际结算为准。 |
| 雷 ↔ 风 | 实际抽牌时，青绿风流带少量紫色细光沿手牌区域收拢，形成“引雷回流”；不生成攻击落点或护盾。 |

派蒙强化通过融合纹样更清楚、边缘多一圈短光强调，不增加虚假的打击次数。连携额度耗尽或奖励未发生时，不播放奖励成功的融合特效。

## 适中强度的制作约束与验收

- 特效重心留在武器、目标接触点和人物身前，避免遮住人物面部、血量、格挡数字、意图与手牌；仅靠黑白轮廓也应能区分风的曲线、岩的多边形、雷的折线。
- 普通元素攻击不额外震屏；岩系重量优先用姿态、动作曲线和短促落点表现。连携可以更亮、更饱满，但不持续闪烁或叠加长时间震动。
- 多目标攻击共用一次人物动作，各目标按真实命中生成局部反馈；多段攻击跟随实际段数，限制同时存在的尾迹和粒子，快速出牌时及时回收。
- 动画不等待特效自然播完才推进规则；快速模式缩短准备和回收，保留可辨认的命中与获得格挡瞬间。中断、死亡或离开战斗时清理临时节点并恢复姿态。
- 人工验收至少覆盖普通攻击、普通防御、全部格挡、部分格挡、直接受伤、零伤害、非攻击扣血、连续受击与致死中断，以及六套基础特效、攻防混合牌、三组连携、派蒙强化、连续出牌及快速模式。检查无误导性伤害/护盾、无残留和遮挡；逻辑测试另行确认伤害、格挡、抽牌、连携额度与随机数不变。

## 技术确认项

角色工厂直接创建TravelerRig，使用11块独立贴图区域构成关节层级；原body.png保留作为来源及兼容资源。BaseLib 3.4.7已提供原生触发器到AnimationPlayer的转发，animation.gd再将动作名交给分层控制器。实际伤害和获得格挡通过原生CombatHistory同步事件进入只读演出适配，区分全挡、部分格挡、受伤和非攻击扣血；不按卡名猜命中次数，不提前读取随机目标。

短暂的连携上下文只选择融合特效，不修改结算；派蒙强化沿用原有奖励结果。动画和粒子自行更新、限量并释放，不加入游戏规则等待。素材来源与提示见[分层素材记录](../art/TRAVELER-COMBAT-LAYERS.md)，验证证据见[开发验证](../tests/COMBAT-PRESENTATION.md)。

无GUI检查覆盖资源、节点、钩子、释放及逻辑只读性；动作观感、遮挡、缩放和节奏需另行人工试玩。下一步建议先评审普通攻防和三种受击结果的动作样例，再扩为风/岩/雷的攻击与防御演出。
