# 2026年10月22日卡牌调整

本轮根据用户11项要求修改，奖励池由18张增加到19张（8攻击、7技能、4能力；8普通、8罕见、3稀有）。原有未提交的罗盘升级和联机大厅改动继续保留。

|---|---|

| 顺风整备 | 0费抽1；基础消耗，升级不消耗 |
| 三相终击 | 基础2费10基础伤害；升级1费12基础伤害。每次连携+4、最多+12继续保留 |
| 雷痕 | 基础5伤害、1易伤；升级7伤害、2易伤。仍先伤害、后易伤、再连携 |
| 雷霆余响 | 2费，升级1费；本场战斗连携基础攻击、格挡各+2，抽牌+1，不与派蒙叠加。替换原全体非攻击伤害 |
| 雷霆连锁 | 新增TC_C19，1费雷元素罕见攻击；随机3击，每击3伤害，升级4击。每击重选存活目标，整张牌只推进一次连携；暂复用现有雷元素插图 |

## 叠加与边界

- 雷霆余响一份使连携变为6格挡、6基础追击、抽2。与派蒙同持时取较高奖励值，一份余响加派蒙仍为8格挡、8基础追击、抽2；不会变为10/10/3。多份余响的+2/+2/+1相加；与派蒙依旧取较高值。力量等原生修正随后作用于追击；风的指引和升级罗盘的额外抽牌不受余响或派蒙放大。
- 基础与升级共鸣使用两个独立能力计数，避免混合持有时把两类回能都错误安排到同一次奖励；同类多份回能相加。
- 初始罗盘力量每回合最多获得1次，第三次“实际奖励”才触发；罗盘不再有抽牌冷却。没有实际收益的连携仍消耗额度，但不计实际奖励。
- 3次基础连携上限保留给无罗盘状态；持有旅途或无界罗盘时提高为4次。三相终击伤害加成仍最多计3次。
- 随机攻击使用游戏原生战斗目标随机数；自动出牌及额外重复结算维持不推进连携。
